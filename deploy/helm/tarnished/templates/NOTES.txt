1. Access Tarnished:
{{- if .Values.ingress.enabled }}
   URL: http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}
{{- else }}
   kubectl port-forward svc/{{ include "tarnished.fullname" . }} 5577:{{ .Values.service.port }}
   Then open: http://localhost:5577
{{- end }}

2. First-time setup:
   After migrations/startup, create the first admin account in the browser.
   Setup works only once. Later accounts are administrator-managed.
   Lost access: use the recovery command from an operator terminal:
   kubectl exec -it -n {{ .Release.Namespace }} deploy/{{ include "tarnished.fullname" . }} -c {{ .Chart.Name }} -- ./entrypoint.sh manage reset-password --email owner@example.com
   Passwords are hidden terminal input.
   Optional --reactivate --recover-admin --revoke-all-keys recover authority/clean up keys.
   Recovery requires the existing configured secret and migrated schema.

3. Check status:
   kubectl get pods -l app.kubernetes.io/name={{ include "tarnished.name" . }}
